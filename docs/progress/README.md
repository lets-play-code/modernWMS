# 进度文档

本目录用于记录任务在不同阶段的状态，而不是沉淀长期业务或技术知识。

## 子目录说明

- `planned/`：已识别、待开始、待批准或待执行的事项
- `active/`：正在进行中的事项与阶段性记录
- `archive/`：已经完成的历史归档

## superpowers 文档规则

AI 工作流文档统一放在本目录下：

- 设计 / spec：`planned/superpowers/specs/`
- 实施计划 / plan：`planned/superpowers/plans/`
- 完成后的历史归档：`archive/superpowers/`

## 与长期文档的边界

如果某项内容已经不再只是过程信息，而变成了长期有效的知识，应迁移到：

- `../domain-model/`
- `../software-design/`
- `../requirements/`
- `../development-standards/`
