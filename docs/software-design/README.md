# 软件设计文档

本目录存放长期有效的软件设计资料，关注“系统如何被设计与实现”。

## 当前文档

- `api-design.md`：基于当前代码库整理的 API 设计、权限模型、分页搜索约定、UI 页面协作规范

## 建议放置的内容

- 架构设计
- 部署架构
- API 设计
- 集成设计
- 数据流设计
- UX / 交互设计
- 非功能设计（性能、可靠性、安全等）

## 组织建议

可按以下两种方式维护：

1. 一个主题一篇文档
2. `README.md + 多篇专题文档`

## 与其他目录的边界

- 业务概念、上下文、用户旅程：放 `../domain-model/`
- 需求来源、背景、验收：放 `../requirements/`
- 通用研发规则与检查项：放 `../development-standards/`
- AI 工作流中间产物：放 `../progress/`
